Connect the extension one-time, on this machine only

The browser extension and this backend share one access token. Because you opened this page from the backend itself, the token can be handed over automatically.

Open the dashboard
  1. Click the Twin-Brain icon in your browser toolbar → the gear → Connection.
  2. Press auto-fill there: the extension asks this backend for the token and saves it.
  3. If auto-fill is disabled (AUTO_PAIR=false), paste the token above instead.
